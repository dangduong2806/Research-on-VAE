# Vanilla VAE Research

A modular research-oriented implementation of Vanilla VAE whose mathematical core follows the `VanillaVAE` implementation in AntixK/PyTorch-VAE.

The current files form the initial project scaffold. Implement modules in this order:

1. `src/data`
2. `src/models/encoders`
3. `src/models/latent`
4. `src/models/decoders`
5. `src/models/vanilla_vae.py`
6. `src/losses`
7. `src/engine`
8. command-line scripts and tests
